# Drexie Jaira Litaoen — Portfolio

A responsive personal portfolio for sharing my background, interests, and learning journey in Information Technology and Enterprise Resource Planning.

## Project files

- `index.html` — portfolio content and page structure
- `styles.css` — layout, responsive styles, and color themes
- `script.js` — scroll-triggered section reveal animations

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.
